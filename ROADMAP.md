# UpNext Roadmap

## Vision
The Goodreads for TV shows - track what you watch, rate shows, and connect with friends.

---

## Phase 1: Core MVP (Complete)
- [x] Search for TV shows via TMDB
- [x] Add shows to your list with status (Watching, Waiting, Watchlist, Completed, Dropped)
- [x] Mark episodes as watched
- [x] "Mark All" to mark entire seasons
- [x] Progress tracking with accurate aired episode counts
- [x] Streaming service info (where to watch)
- [x] Home screen with "Up Next" and "Coming Soon" sections
- [x] Dark mode UI
- [x] TestFlight deployment

---

## Phase 2: Ratings & Reviews
- [ ] **Star ratings for shows** (1-5 stars)
- [ ] **Written reviews** for shows
- [ ] **Season ratings** (rate individual seasons)
- [ ] Display average ratings on show cards
- [ ] "Your rating" vs "Community rating"

---

## Phase 3: Social Features
- [ ] **User accounts** (Supabase auth - email/Apple Sign-In)
- [ ] **User profiles** with watch history and ratings
- [ ] **Follow friends** to see what they're watching
- [ ] **Activity feed** showing friends' recent activity
- [ ] **Share watchlist** with partner (original sync feature)
- [ ] **Recommendations** based on friends' ratings

---

## Phase 4: Discovery
- [ ] **Browse popular shows** by genre
- [ ] **Trending shows** this week
- [ ] **Personalized recommendations** based on your ratings
- [ ] **"Because you watched X"** suggestions
- [ ] **Lists** (custom user-created lists like "Best Sci-Fi")

---

## Phase 5: Engagement
- [ ] **Push notifications** for new episodes
- [ ] **iOS widgets** showing upcoming episodes
- [ ] **Watch reminders** ("New episode tonight!")
- [ ] **Streaks** for consistent watching
- [ ] **Stats dashboard** (shows watched, hours tracked, etc.)

---

## Phase 6: Polish & Growth
- [ ] **Android release**
- [ ] **App Store release** (public)
- [ ] **Onboarding flow** for new users
- [ ] **Import from other apps** (Trakt, TV Time)
- [ ] **Export data**
